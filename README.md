# Analisis-Volume-lambung-kapal-

Tugas 2 - Volume Dua Lambung Katamaran
Metode
Skala: 1 kotak grid = 4 x (dash-kosong 5+5 cm) = 40 cm x 40 cm (grid 20 kotak = 8 m).
Stasiun tiap 1/2 kotak (dx = 20 cm), dari sekat reserve buoyancy buritan (st. 4) sampai sekat reserve buoyancy haluan (st. 36). Panjang lambung yang dihitung = 640 cm.
Lebar dibaca dari tampak atas (tepi luar), tinggi dari tampak samping (sheer sampai dasar).
Dasar dianggap datar (tanpa keel), sehingga penampang berbentuk persegi panjang: A(x) = lebar x tinggi.
Volume = integral A(x) dx dengan aturan trapesium dan Simpson (32 interval, genap).
Bagian reserve buoyancy (ujung buritan dan haluan) tidak dihitung.
Kedua lambung dianggap identik, sehingga V_total = 2 x V_satu lambung.
